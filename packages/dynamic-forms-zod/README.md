## When you need this

A FormConfig written in TypeScript with `as const satisfies FormConfig` is already checked by the compiler. This package covers the cases the compiler cannot reach:

- Configs that arrive as JSON at runtime, from an API or a CMS
- Configs generated by an LLM, where you want a JSON Schema to constrain the output and a validator to check it
- CI gates over config files, via `@ng-forge/dynamic-forms-cli`

It has no Angular dependency and runs anywhere Node does.

## Installation

```bash
npm install @ng-forge/dynamic-forms-zod zod
```

`zod` is a peer dependency (`^3.24.0`).

## Validating a config

```typescript
import { validateFormConfig } from '@ng-forge/dynamic-forms-zod/validate';

const result = validateFormConfig('material', configFromApi);

if (!result.valid) {
  console.error(result.errorSummary);
  for (const error of result.errors ?? []) {
    console.error(`${error.path}: ${error.message}`);
  }
}
```

`validateFormConfig` takes the UI integration (`material`, `bootstrap`, `primeng`, or `ionic`) because each adapter accepts a different set of field types and props. Use `isValidFormConfig` when you only need the boolean.

## Generating JSON Schema

Useful for constraining an LLM's structured output to configs that will actually render:

```typescript
import { getFormConfigJsonSchema, getFieldTypeJsonSchema } from '@ng-forge/dynamic-forms-zod/validate';

const configSchema = getFormConfigJsonSchema('material');
const inputSchema = getFieldTypeJsonSchema('material', 'input');
```

## Using the schemas directly

The adapter entry points export the underlying Zod schemas if you want to compose them into your own validation:

```typescript
import { MatFormConfigSchema } from '@ng-forge/dynamic-forms-zod/material';
import { BaseFormConfigSchema } from '@ng-forge/dynamic-forms-zod';

const parsed = MatFormConfigSchema.safeParse(config);
```

## Entry points

| Entry point                             | Contents                                        |
| --------------------------------------- | ----------------------------------------------- |
| `@ng-forge/dynamic-forms-zod`           | Adapter-agnostic base schemas                   |
| `@ng-forge/dynamic-forms-zod/validate`  | `validateFormConfig`, JSON Schema generation    |
| `@ng-forge/dynamic-forms-zod/material`  | Material schemas (`MatFormConfigSchema`, props) |
| `@ng-forge/dynamic-forms-zod/bootstrap` | Bootstrap schemas                               |
| `@ng-forge/dynamic-forms-zod/primeng`   | PrimeNG schemas                                 |
| `@ng-forge/dynamic-forms-zod/ionic`     | Ionic schemas                                   |
